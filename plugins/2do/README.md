# 2Do Tools Plugin

This plugin registers the `2do` MCP server with clients that support plugin
marketplaces.

Requires macOS on Apple Silicon (arm64) with native arm64 Python 3.11 or newer. Intel Macs and Python running under Rosetta are not supported.

Install the `2do` command first, then install this plugin from the marketplace.
The plugin intentionally uses the plain `2do` command so each client can run the
server from the user's normal install location.
